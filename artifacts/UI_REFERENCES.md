# UI direction

Main menu reference: Alien: Isolation (2014).
https://www.mobygames.com/game/68903/alien-isolation/screenshots/windows/736050/

Combat HUD reference: DOOM (2016).
https://interfaceingame.com/games/doom/
https://www.wsgf.org/dr/doom-2016/en

Applied: left-aligned white menu typography over the actual game scene, a pale selection strip, no opaque cards, bottom-left health, bottom-right magazine count with smaller reserve ammunition, compact neutral reticle. Contextual guidance remains temporary.

The game uses its own scene and title. Reference screenshots are not packaged as game assets.
